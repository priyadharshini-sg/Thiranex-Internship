# Campus Companion – Mobile App Wireframing

## Project Overview
Campus Companion is a student-friendly mobile application designed to help college students manage their academic activities in one place.

## Objectives
- Simplify timetable management.
- Track assignments and deadlines.
- Manage important reminders.
- Improve student organisation.

## Tools Used
- Figma
- GitHub

## Design Process
1. User Research
2. User Persona Creation
3. User Flow Design
4. Low-Fidelity Wireframing
5. Design Thinking Documentation
6. Prototype Testing

## App Screens
1. Welcome / Login
2. Home Dashboard
3. Timetable
4. Assignments
5. Reminders
